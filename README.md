# projeto-masso-ana

Landing page responsiva para **Massoterapia & Terapias Holísticas**, desenvolvida com foco em experiência do usuário, estética acolhedora e apresentação profissional dos serviços.

---

## ✨ Sobre o projeto

Este projeto foi criado para apresentar de forma clara, elegante e estratégica os atendimentos de uma terapeuta manual, reunindo informações sobre:

- serviços oferecidos
- benefícios das técnicas
- apresentação profissional
- contato rápido via WhatsApp
- navegação simples e agradável em dispositivos móveis e desktop

A proposta visual busca transmitir **bem-estar, cuidado, leveza e profissionalismo**, alinhando design, conteúdo e conversão.

## 🎯 Objetivos do projeto

- Criar uma landing page profissional para divulgação de serviços
- Melhorar a presença digital da terapeuta
- Facilitar o contato com potenciais clientes
- Apresentar os serviços de forma visual e organizada
- Desenvolver uma interface agradável, moderna e responsiva

---

## 📱 Funcionalidades

- Layout responsivo
- Seções organizadas para apresentação dos serviços
- Cards com técnicas e benefícios
- Botão flutuante para WhatsApp
- Navegação intuitiva
- Estrutura pensada para futura expansão
- Design com identidade visual acolhedora e sofisticada
